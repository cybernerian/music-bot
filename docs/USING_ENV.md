Create `.env` file
---
``API_KEY = os.getenv("LASTFM_API_KEY")
USERNAME = os.getenv("LASTFM_USERNAME")``
---

When you clone this repo create an `.env` file. Paste code snippet above inside the new `.env` file and replace the quoted paramaters with your API credentials

To get the API credentials go **[here](https://www.last.fm/api/account/create)**. Make sure you use the same email as your last.fm account.
